## Evidence limits

The eight axes and sixteen systems are an editorial working framework grounded in scoped sources, not a systematic literature review or a complete academic taxonomy. Source records distinguish research, commentary, platform guidance, web standards and engine documentation.

Static figures cannot establish controller focus, hover semantics, transaction safety, user performance, Chinese readability or immersion. The Factorio GUI study includes a historical developer design mockup; Dead Space references are official settings-guide figures. Non-pixel cases support structural comparisons, not pixel-asset production.

Public files contain original analysis, source URLs and remote image embeds. Commercial reference-image binaries and local review paths are excluded. No player study was conducted. Use the UI design contract and evaluation protocol to establish project-specific evidence.
