# v1.3.1 视觉修订记录

2026-10-29。用户明确否定 v1.3.0 的视觉效果。此前交易与脚本通过，不能说明设计原则已落到画面，也不能抵消框体、字体、像素颗粒与构图的问题。

本轮实际查看旧版三张截图，并独立对照 Moonlighter 的书页结构与 Stardew Valley 的室内对白官方图。观察范围是静态组织，不借它们声称本例可用性已获证明。

## 已修改的画面

- A/C 撤下金色厚木框与宝石角饰，新增一次生成的 [朴素纸木空框](../examples/rural-shop-demo/assets/plain-panel-provenance.json)，原图九宫格切边24px、实际边宽8px。
- 大号 Fusion 字只承担短标题；主要内容按身份24、决定18、阅读14、辅助12px分层。装饰不再与商品、按钮同时争当标题。
- C 从几乎满高的侧栏改成底部870px短窗，3×2商品格，店主和柜台保持可见。短商品名服务扫描，可访问名称和详情保留完整品名。售罄商品在格中直接显示“今日售罄”。
- B 左页是货目，右页是本次购入记录，数量、合计和付款沿账目顺序组织。真实种植/使用条件保留为简洁摘要，避免为了少字丢失水田、成长天数或施肥条件。
- 比较工具移到底部，降低视觉重量；给村名稳定的小底面，避免白字压在白花上。

## 当前截图与操作证据

[木框](../examples/rural-shop-demo/screenshots/01-wood.jpg) · [账本](../examples/rural-shop-demo/screenshots/02-ledger.jpg) · [短交易窗](../examples/rural-shop-demo/screenshots/03-world.jpg) · [窄屏账本](../examples/rural-shop-demo/screenshots/04-mobile.jpg)。源文件与截图哈希见 [runtime-review.json](../examples/rural-shop-demo/runtime-review.json)。前三张均为1280×720，240钱、9/24格、预览购买3包小青菜的同状态比较。

在1280×720检查三方案与最长蓝莓名称，正常面板内容未溢出；另查看1458×891世界方案。390×844账本允许面板内滚动，未横向溢出。实际复核购买3包后240→204钱、9→12/24格，并切换方案确认保持；缺款、满包、售罄均有原因并禁购。Escape返回入口焦点、E重新打开。前端模块语法检查通过，最后未捕获控制台警告/错误。模型与检索工具未改，既有测试不作为此次美术证明。

独立复查认为新版C的店主可见性、商品辨认、装饰重量及文字层级已有明确修正，并指出售罄标记缺失；该项已修复。账本的信息缺失由代码复查发现，真实条件摘要已补回。

## 保留的界限

这是本轮实施者与独立agent的有限审阅，用户尚未接受修订版。场景与图标的源像素颗粒仍有差异；硬alpha失败、统一有限色板和原生逻辑网格未知继续记录。新面板也未被认证为严格原生像素生产资产。没有玩家实验、实体触屏、屏幕阅读器或全分辨率测试。

旧版原始截图和功能记录已固定到 [v1.3.0提交](https://github.com/qianhua76123-pixel/pixel-game-art-director/tree/29ab69889fb375611fcc42cb471aaf751fede336)，防止用新截图替旧视觉结论背书。
