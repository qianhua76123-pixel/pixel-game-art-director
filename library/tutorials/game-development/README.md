# 游戏开发教程分册

本分册收录24个独立的 Godot 官方教学页面，统一固定为 **4.5 文档分支**。每篇包含中文任务导读、操作路线、练习、验收、原文主内容和本地配图。它们不全是像素风示例；学习目标是将可复用的二维引擎知识应用到像素项目。

## 按任务选读

- **第一次做完整游戏**：DEV-001 → DEV-002 → DEV-003 → DEV-004 → DEV-005 至 DEV-011。官方完整项目的默认美术不是严格像素画。
- **俯视村庄、室内和庭院**：DEV-012 → DEV-016 → DEV-014 → DEV-015 → DEV-017 → DEV-018，再接 DEV-013、DEV-020、DEV-021。
- **画面模糊、缩放不齐或透明边缘异常**：先读 DEV-021 与 DEV-022，分开检查显示缩放、纹理过滤、压缩和源素材。
- **夜景、场景纵深和动作状态**：DEV-019、DEV-024、DEV-023。只引入当前项目需要的功能。

完整路径和来源元数据见 [game-development.json](../../manifests/game-development.json)。

## 阅读边界

- 中文部分是整理者的教学编排；英文部分是授权原文的格式转换，不把中文导读宣称为官方逐句翻译。
- 原文 GDScript 与 C# 示例均保留，并用对应代码围栏标记。不要把两种语言代码直接混用。
- CC BY 3.0 署名、来源、许可链接与本地配图清单位于每篇末尾。单独复用素材包仍需查看其各自许可。
- 5段嵌入动态演示保留原始 webm 及静态抽帧辅助阅读；抽帧不是完整动作、音轨或字幕转录。
- 原文主内容快照存放于 `../../sources/game-development/`，用于核对转换。快照中的原相对图片路径未改写，不作为离线 HTML 阅读器；离线阅读请打开本分册的 Markdown。
- 本次验证针对文档、图片与转换完整性；未声称逐一运行全部引擎示例或完成练习。

## 常用术语

| 中文 | Godot 名称 | 适用位置 |
| --- | --- | --- |
| 场景实例 | Scene instance | 重用角色、树、道具的节点结构 |
| 输入动作 | Input action / Input Map | 将键盘、手柄映射到玩法动作 |
| 角色物理体 | CharacterBody2D | 受脚本控制、需要碰撞响应的角色 |
| 触发区域 | Area2D | 拾取、伤害区、进入提示等重叠检测 |
| 碰撞所属层 | Collision layer | 这个物体属于什么类别 |
| 碰撞检测遮罩 | Collision mask | 这个物体要检测哪些类别 |
| 图块集 | TileSet | 图块切分与碰撞、导航、地形等属性 |
| 地图层 | TileMapLayer | 在场景中绘制、组织图块的节点 |
| 画布层 | CanvasLayer | 固定 HUD 与世界画布分离 |
| 整数缩放 | Integer scale mode | 保持像素块尺寸均匀的显示策略 |
| 动画帧资源 | SpriteFrames | AnimatedSprite2D 的动作与帧列表 |
| 动画状态机 | AnimationNodeStateMachine | 在动作状态之间控制转换 |
