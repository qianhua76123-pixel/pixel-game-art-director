# 青禾种子铺：三种可操作界面

同一乡村商店、同一套商品、同一份钱袋与库存，比较三种界面结构。中文商品名、数量、价格、库存、说明与交易反馈均由真实文本层渲染；背景、木框、账本和商品来自本地光栅图像。它是独立的交互小样，没有漫游、存档或完整种植系统。

v1.3.1 根据用户对上一版视觉效果的明确否定重做。调整内容包括大面积像素字、厚金框、方案之间过于相似的表单，以及世界方案的高侧栏。交易模型继续共用；功能测试通过不作为新画面质量已获认可的证据。

## 运行

在仓库根目录运行：

```bash
python3 -m http.server 8775 --bind 127.0.0.1 --directory examples/rural-shop-demo
```

浏览器打开 `http://127.0.0.1:8775/`。使用 ES 模块，不能直接双击 HTML 的 `file:` 地址。运行时无需外部图片、字体服务或构建依赖。

## 同任务对比

### 一 · 木框纸面

左侧列表同时显示价格与余量，右侧查看详情、数量与结算。取消旧金色宝石角框，改用朴素纸面和窄木边；源图四边各取 24px，通过九宫格显示为 8px 边框。桌面宽度上限 884px，仍会遮住一部分场景。

![木框纸面：购买三包小青菜种子的预览](screenshots/01-wood.jpg)

### 二 · 柜台账本

左页为“今日货目”，右页为“本次购入”：商品身份、数量、花费与买后余额按账目组织。右页隐藏商品说明、成长时间和种植提示，避免重复另一方案的完整详情表单；商品数据仍保留，种植季节也仍不限制本例购买。账本、算盘和纸袋建立柜台联系。窄屏重排为平铺账目，并使用新朴素面板，不将整本书缩小。

![柜台账本：同一笔交易](screenshots/02-ledger.jpg)

### 三 · 世界与轻面板

从店主入口进入，桌面交易窗改在画面底部，最大宽度 870px；左侧 3×2 商品格，右侧显示当前商品与本次交易。商品格采用中文短名，详情显示全名，可访问标签保留完整商品名、价格及余量／售罄信息。入口与交易窗分开，保留店主和上方世界的空间联系；窄屏转为单列内容并允许面板内滚动。

![世界与轻面板：村落和交易同时可见](screenshots/03-world.jpg)

v1.3.1 的桌面预览按原生 1280×720 输出，不用缩放拼图替代实际界面。各图采用 240 钱、9/24 格、选中小青菜种子 3 包的相同初始比较状态；36 钱是预览花费，204 钱是购买后的预计余额。截图更新与运行核验状态见 [本次审阅记录](../../validation/UI-REVISION-V1.3.1.md)，不沿用上一版 1458×891 截图作为新版证据。

## 文字与材质层级

主阅读区采用四个角色，动态文字没有烘焙进图像：

| 角色 | 主字号 | 实际用途 |
|---|---:|---|
| 身份 | 24px | Fusion Pixel 店名、界面标题、村名 |
| 决策重点 | 18px | 系统中文商品详情标题、账目标题及重点交易读数 |
| 阅读 | 14px | 系统中文正文、桌面商品名、常规价格和操作文字 |
| 辅助 | 12px | 库存、持有量、单位、状态说明；窄屏商品短标签 |

Fusion Pixel 不再覆盖所有按钮、价格和商品名。账本的真实条件摘要采用12px系统中文辅助角色；底部比较工具的个别文字为 10–12px。具体控件覆盖与最终显示需按当前 CSS 和实际窗口审阅，不能仅靠字号表宣称视觉已通过。

新面板避免金属高光、宝石角饰和密集纸纹；`border-image` 负责边角、边缘与中心分区，不是把整张装饰框任意拉伸。账本桌面仍保留实体物件背景，窄屏使用同家族平面纸面。

## 操作与状态

- 点击商品，输入 1–99 的整数数量，或用加减按钮调整；按钮显示本次数量和总价。
- 点击购买会同步更新余额、背包占用、库存和持有量；切换方案保留这些数据。
- `Esc` 收起并把焦点还给店主入口；`E` 打开；商品格中的方向键按当前行列移动。
- 底部比较栏中的“状态”提供正常、缺款、满包、全部售罄夹具及恢复初始状态。它是审核工具，不是游戏系统内容。
- 失败交易不扣款；小数等无效数量会给出原因。购买后的短暂忙碌状态防止同一次快速重复激活。
- 刷新重置，未写入浏览器存储。每单位商品暂占一格，容量为 24；这只是小样规则，详见 [数据合同](data-contract.json)。

## 一致性与制作来源

[项目主题合同](theme-contract.json) 固定了共同主题、角色差异和有理由的例外。三种方案改变结构，沿用同一场景、商品图集、纸木材质、绿色购买动作和锈红错误信息。UI、图标与世界允许不同表现尺度，但不能分别选择另一套画风。

仓库保留五张由内置图像生成工具制作的原始 PNG，未经图像后处理。原四图的 [提示词](assets/prompt-set.md) 与 [来源记录](assets/asset-provenance.json) 保留；本版新增 `plain-paper-panel.png`，通过一次独立生成获得，详见 [新面板提示词](assets/plain-panel-prompt.md) 和 [来源、哈希与九宫格测量](assets/plain-panel-provenance.json)。旧 `wood-panel.png` 已退出当前界面，仅保留为历史源图；当前使用其余四张图。

标题使用原始 [Fusion Pixel 12px 字体](assets/font/font-source.json)，保留 [OFL](assets/font/OFL.txt) 及上游许可。五张 AI 图只在实际持有权利的范围内按根 MIT 提供，不保证独占性或独立版权；字体继续按 OFL 分发。

这些是**像素风格光栅原型素材**。图集有半透明像素，严格硬 alpha 门槛失败；原生逻辑网格、统一有限色板和逐物体光照仍未完成生产验收。源图尺寸大、CSS 设置 `pixelated` 都不能证明它是合格的原生像素素材。背景中的店主未拆成角色动画，整幅村落也不是可复用地形图块。

## 验证

```bash
node --test examples/rural-shop-demo/shop-model.test.mjs
python3 scripts/validate_theme_contract.py examples/rural-shop-demo/theme-contract.json --json
```

验证器核查合同结构和证据绑定，不自动判断画面美感。此示例预期返回结构 `PASS`、记录 `INCOMPLETE`、严格像素生产 `OBSERVED_FAIL`，退出码 `1`；这是对实际源图的诚实记录，不是运行失败。

v1.3 的交易、状态、焦点和不同视口检查保存在 [历史报告](../../validation/SHOP-COHESION-V1.3.md)。本次更改了布局和文字，不能直接继承这些检查为新版通过；v1.3.1 的截图、运行检查和未完成项以 [本次审阅记录](../../validation/UI-REVISION-V1.3.1.md) 为准。桌面审阅尺寸为 1280×720，窄屏为 390×844，见 [窄屏截图](screenshots/04-mobile.jpg)。未进行真实玩家研究、屏幕阅读器或实体触屏测试。

验收要分别回答交易是否正确、实际界面是否可读，以及用户是否接受视觉效果；测试通过数量不能回答最后一个问题。研究依据：[同主题画面拆解](../../references/visual-game-studies.md)、[整体主题约束](../../references/theme-cohesion-contract.md)。
