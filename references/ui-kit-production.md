# 像素 UI 零件库：拆分、生成与装配

在需要制作、扩展或复盘一套像素游戏 UI 时阅读本页。本页讲零件怎么拆、怎么生成才更省次数、代码允许做什么、界面怎么由零件拼起来。它不替代 [系统模式](ui-system-patterns.md)、[八个设计维度](ui-design-foundations.md) 或 [一致性检查](consistency-review.md)。先有玩家要做的决定和视觉主题，再进入制作。

教程检索、案例截图和风格配方只是研究输入，不能直接当作零件库或游戏成品。

## 先拆，再画

一张完整界面按三层拆开，而不是先生成整屏再裁切（整屏只用于排法小样）。

- **按入口**：哪个世界触点或全局菜单打开它。入口决定排法家族，例如：仪式大面板、右侧窄面板、左右分栏、更强仪式感的异形纸、居中压在场景上的大面板。
- **按图层**，从后到前：场地或世界背景 → 面板框 → 标题绦带 → 内容零件 → 项目字体排字 → 必要时才出现的动效层。
- **按零件与内容**：框、绦带、按钮、列表行、槽位、纹饰是可复用零件；立绘、文案、场地画是按对象换进去的内容。

先写出零件清单、每种零件的状态（至少 normal / hover / pressed / disabled，选中和焦点要能区分）、逻辑尺寸和九宫格切法，再生成。

## 按族打包生成，不要默认一件一图

目标是：生成次数尽量少，切开后能用，且线宽、色板、角饰语言保持同一套规矩。

**默认按族打包**，同一张图里只放类型相近、尺度相近的零件，彼此留出宽洋红间隔，生成后再按连通域切开：

- **同一控件的全部状态**必须画在一张图里（例如按钮的 normal / hover / pressed / disabled），不要为每个状态单独发明一种造型。
- **同族零件**放在一张图里。例如框族（面板 + 子面板 + 标题绦带）、按钮族（主按钮四态 + 次按钮四态）、槽位或列表行的各状态、同一尺度的图标列。同族同图时，线宽和金色更容易锁住，次数也比一件一图少一半左右。
- **单独出图**留给：需要大画幅、干净九宫格的关键框（当家族图会把它挤小或挤软时）；以及按对象替换的内容（立绘、场地、仪式道具）。这些不要和柜线零件混在一张图里。
- **不要把整套柜线**（大面板 + 绦带 + 两组按钮）默认塞进一张图。在通用文生图模型上的对照里，10 件可以切干净、风格也统一，但角饰会糊、轮廓会变软，达不到生产标准。整套一张只适合作为廉价排法小样。
- **不要生成完整成品界面再裁切**作为零件来源。

只给文本提示，不向模型发送参考图（项目若另有“用已入选零件作风格锚点”的流程，另写清楚，不要和文本生成混用）。

提示词应写明：

- 纯洋红底（`#ff00ff`），画面上只有这一族零件，件与件之间有宽间隔、互不接触
- 绝对不写字、字母、数字或水印；文字是后加的内容层
- 项目色板（颜色名 + 十六进制），轮廓线宽（通常为 1 个艺术像素），同一张图里所有零件共用
- 硬边像素、可见方块、平涂；禁止抗锯齿、渐变、模糊、软阴影和用代码补出来的光晕
- 正视、正交；需要对称的零件写明对称
- 中间留空，把排字区和立绘窗口空出来
- 同族零件的像素尺度一致；按钮等成排零件写明宽度、高度、倒角相同

**先跑一版，落选再补。** 不要默认每件出两版。装饰过满的一版即使精细，也应让给更克制、更易九宫格的一版。家族图里只有一件不合格时，只重做该族或该件，不要整库重跑。

共用同一段风格合同（色板、线宽、像素尺度、视角、洋红底、不写字），比把不同措辞散落在各条提示里更能锁住风格。

## 代码不绘制设计图

原图之后，代码只做这些事：抠洋红、检测网格并像素化、锁定项目色板、按连通域切片、按生成图自身的重复带做九宫格、摆放、用项目字体排字。框、纹饰、印章、分割线、状态、高光和雾气都不是代码画出来的。原图的颜色数量会很多，这是正常的，必须经过像素化与锁色才能入库。

九宫格只重复已经生成好的中间带，不拉伸角饰或居中的结。若目标尺寸会把装饰拉变形，就按新尺寸重新生成，或预烘焙一块已适配的图，而不是在运行时硬拉。

排字从零件自己的内容矩形出发：取最大的平涂区域，避开角饰。容器不够就通过九宫格把盒子撑大，直到真实长文案放得下；不缩小字体。居中按字形墨盒计算，不按字身框。按钮若纵向拉伸会破坏倒角，应保持原生高度，只把标签居中。

动效是单独一层状态机，只留给少数高潮时刻，并且可跳过。日常界面保持克制。不要用抖动或铺满的网格去冒充光晕；选中态用位移和实心描边这类能画进零件里的办法。

## 先审原生像素，再扩展

用真实长文案、真实数值和边界状态验证布局，再装饰。先在 1× 和整数倍最近邻放大下自审，再交给用户或下游。改设计语言之前先说明问题和两个选项。

机器检查（件数字是否与清单一致、间隙是否可切、尺寸是否齐、色板、透明、网格、九宫格边距）不能替代打开联系表与原图的视觉审查。重点看：轮廓是否仍是统一线宽、角饰有没有糊成团、金色有没有过亮、同族零件的尺度是否一致。

一套零件要能拼出该项目的全部入口排法，并在字号、线宽、金色用量和留白上保持同一套规矩。
