# 商店界面实图对照

运行 `python3 scripts/preview_shop.py`，打开 `/review/shop-benchmark/#result`。

右侧是本轮重新制作的人物、六件商品与UI的实际运行截图。左侧切换 Stardew Valley 的 Pierre 买种界面和 Moonlighter 的药水商人服务。新稿可切换正常选货、蓝莓售罄和购买后回执。

默认并排概览便于同屏看构图；选择“最终尺寸”后，两栏各显示为1280×720，窄窗口可横向滚动。参考源截图为1920×1080，新稿源截图为1280×720。下方另有原图局部，截图像素不能代指游戏原生逻辑像素。

新稿的半身店主与柜台同图制作，六商品新画，选货与结算合成一张账板。当前环境和头发仍有较密的插画纹理，用户视觉审核尚未完成。v1.4已被用户否定；它与更早截图保留为历史记录，不能以技术检查替代实际效果。
