# 青禾种子铺：整屏审视与下一轮制作规划

**状态：PROPOSED。** 当前 v3 整体效果已被用户否定。本页提出制作方向，不代表新美术已获接受；本轮不替换运行中的商店，也不继续生成素材。

范围是这一屏商店及其最低限度的可复用组件。保留六件商品、价格、库存、已有量、季节、容量和交易机制；不扩展整款游戏 UI，不制作动画。基线为提交 `2e1c6ffd75c525f4933ef4eb1a4ffa0414e97d84` 的 [正常柜台截图](../../examples/rural-shop-demo/screenshots/v3-counter.jpg)，并对照 [售罄](../../examples/rural-shop-demo/screenshots/v3-sold-out.jpg) 与 [成交](../../examples/rural-shop-demo/screenshots/v3-receipt.jpg) 状态。

## 需要重新规划的五种关系

| 标记 | 实际画面中的问题 | 下一轮要建立的关系 |
|---|---|---|
| focus | 窗户、人物面孔、货架纹理和大木框都很抢眼，六件商品分散在大纸面上。 | 场景承担身份与气氛，当前商品和交易成为前景焦点；先确定整屏明暗与留白，再制作精细环境。 |
| grammar | 人物的脸、头发、手和衣褶保留较多插画细节，商品与控件采用另一种简化程度。 | 先为整个项目选定一个风格锚点，规定造型、色彩职责、材质、轮廓与细节取舍；允许不同用途有不同尺度，禁止逐资产重选画风。 |
| catalog | 六个等权小岛负责浏览，选中后只有底色和角标变化，没有充分展示这件商品的区域。 | 浏览区利于比较；选中区用清楚的大图、完整名称和用途解释支持决定。包装造型与材质在实际尺寸下成立。 |
| type | 店名、商品名、余量、条件与结算的视觉重量相近，季节、水田、空耕地等关键限制需要逐字寻找。 | 以位置、留白、字形层级区分名称、价格、条件和次要余量；关键限制靠短标签与正文共同表达。 |

## 推荐的完整屏幕结构

安静的游戏世界与店主身份留在侧边或菜单后方。前景是一张统一菜单表面，包含互相邻接的两个内容区域，不再把每组字段各装一个独立纸框。

- **左侧浏览六件货。** 六条横向货目，各有图标、短名、价格、余量；保持有货、售罄、选中与焦点的区别。六件货不增加空洞的分类导航。
- **右侧判断当前货品。** 展示足够清楚的商品大图、完整名称、已有量、适种季节、成熟时间及关键限制。水稻的水田要求、辣椒的夏播、堆肥的空耕地限制均保留。
- **右下完成交易。** 数量、总价、钱与行囊的变化、购买按钮属于同一阅读组。本笔回执占用稳定位置，不跳到屏幕另一端。店主对白只补充性格与气氛。

例如购买三包小青菜后，购买处显示“已购3包，花费36钱，现余204钱”；如果保持三包供再次购买，动作应明确写“再买3包”。下一笔预测168钱必须被标明为下一笔，不能与本次回执混为同一个结果。这里调整呈现方式，不修改交易公式或默认资源。

## 素材必须按同一套规则制作

先确定一个**整屏项目风格锚点**，包括实际游戏世界应有的造型和细节密度。Pierre 与 Moonlighter 可提供不同关系的观察依据，不能把一种人物、另一种框体和第三种图标拼成“参考融合”。

制作时分开存放场景、人物、柜台前景遮挡、商品和 UI 素材，再放在同一画面审阅。避免把巨大的空账板永久烘焙在背景里；这样才能调整菜单、遮挡和状态，而不必重生整张画面。拆分文件本身不保证风格一致。

同一物品在手持包装、世界道具、背包小图和选中大图中应保持身份：包装轮廓、植物符号、封口、材质和识别色应能对应，细节可按用途取舍。店主若固定拿通用纸袋，应明确是通用包装；若拿的是当前商品，就必须匹配当前选择，不能用固定绿叶纸袋冒充所有商品。

第一份制作包同时包含：人物头与双手；纸袋、粗布袋、陶盆三种材质代表物；框角、货币符号、中文字形、选中与购买按钮。全部放进最终显示尺寸的同一小样里评审，不用放大的单张母版代替。

## 制作次序与可见交付

| 阶段 | 必须交付 | 继续制作前要看到的效果 |
|---|---|---|
| 1 · 构图粗稿 | 同一任务内容的整屏构图草案，含真实中文与数字、整屏风格锚点和主次说明。 | 当前商品与购买位置清楚；场景和人物有身份空间；不靠装饰框撑起整屏。 |
| 2 · 同屏素材小样 | 人物头/手、三材质代表物、UI 框角/文字/货币/选择/按钮一张联系图与一张实装图。 | 造型、材质、色阶和轮廓具有亲缘关系；商品缩到最终尺寸仍清楚；没有一件像外来贴图。 |
| 3 · 一件商品完整状态 | 一件真实商品的浏览、焦点、选中、数量编辑、禁购、提交、成交与返回状态。 | 费用、限制、动作与结果在同一视觉流中；状态变化无需跨屏寻找；本笔结果与下一笔预测可区分。 |
| 4 · 扩展六件商品 | 六商品成组小图/大图、最长品名、售罄、缺钱、满包和库存不足的成组实装画面。 | 六件货身份清楚、大小和材质协调；长内容与异常状态没有破坏主次。 |
| 5 · 环境整合与收尾 | 环境、人物、前景遮挡、菜单共同实装的正常/成交/禁购截图，以及与参考的同尺寸并排页。 | 环境支持交易前景，遮挡和光照成立；进入、操作、离开保留同一套视觉语言。 |

以上阶段是制作依赖，不是自动审美评分，也不规定用户必须逐项授权。每个阶段只凭对应成图和实际操作下判断，不能用源图数量、生成模型、网格或测试通过替代视觉结论。

## 保留、重做与停止沿用

- **保留：** 原交易模型、六个商品 ID 与数值、原有交易测试、Fusion Pixel 文件与 OFL 声明、官方参考及历史证据。字体可复用，字体层级需要重新设计。
- **重做：** 在同屏素材小样确定后，制作核心人物、商品、UI、场景与遮挡素材；重新组织浏览、判断、结算和回执。现有光栅图只作探索记录，不作为已接受的项目母版。
- **停止沿用：** 先生成整张精细背景、再往空板塞文字的顺序；把多个来源独立选风格；用技术指标宣布美术完成。停止沿用不等于删除历史文件。

行囊中未具名的既有占用保持原模型，不凭空补画物品或修改存档。最终交付只覆盖这一屏和上述最小组件，不将尚未制作的世界、动画或其它系统写成完成项。
